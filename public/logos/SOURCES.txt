Downloaded 2026-08-17 and 2026-08-18. Every file was checked to be valid XML
containing no <script> and no external references before being committed. The
only absolute URL in any of them is the SVG namespace declaration.

The two Google files are the marks Google itself serves from gstatic, which is
the CDN behind Google's own product surfaces. They are unmodified: the strip
renders every mark at full color and full fidelity, scaled only by height. That
matters, because the earlier version of this strip forced every logo to flat
monochrome, and recoloring is exactly what Google's brand guidelines do not
permit. Displaying the unaltered mark is permitted use; recoloring it was not,
which is why these two rows were text until the strip went full color.

Three of the five marks are icon only: both Google files, because Google does
not publish downloadable wordmark SVGs for these products, and the Cloudflare
file, which is the cloud glyph on its own. Each of those is paired with the
product name set in the page's own type rather than with a traced or
reconstructed wordmark. Exa and Apify ship real wordmarks and stand alone.

Not included, deliberately:

  Upstash
    Not a dependency of this product, so it does not belong under a heading that
    says "Powered by". Resolved corners, generated imagery, scores, the daily
    generation budget and rate limiting all run on Cloudflare KV. An Upstash
    code path exists and would activate if those credentials were ever set, but
    nothing in the deployed product uses it and no Upstash credentials are
    configured. Listing it would be a claim about the architecture that the
    architecture does not support.

  DataSF
    No strong logo mark, and the open data portal does not publish one. Styled
    text by design, in the same fixed box as every other row.

  Cloudflare press kit
    The official press-kit archive linked from cloudflare.com/press-kit contains
    only JPG and PNG, no SVG. The file above is the mark Cloudflare serves from
    its own root domain, and it carries a <title>Cloudflare logo</title>.
